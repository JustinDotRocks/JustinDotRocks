# Hi there, I'm Justin Smith! 👋

## 🙋‍♂️ About Me
Full stack developer in Newfoundland building cross platform mobile and web apps with React Native, Expo, TypeScript, AWS cloud (Amplify, DynamoDB, Cognito, Lambda) and more. I also work as a QA analyst, so I think about how things break before I ship them.

Lately, I've been focused on AI engineering: a ticket driven workflow where AI writes the code, but every plan, PR and release goes through human review and AI guardrails I built.

## 🚀 Currently Working On

### 📅 FloorWide · MVP in active development
**Event day, minus the chaos.** FloorWide keeps organizers and vendors on the same page from setup to teardown, so everyone knows what's happening and when.
- **Stack:** Expo, React Native, TypeScript, AWS Amplify, Cognito, DynamoDB
- Vendors get in with one tap: passwordless access through single use email magic links
- Invite every vendor at once with bulk invites through AWS SES
- Built for teams, with multi tenant org setup, org scoped data and role permissions
- Live timeline updates and notifications, so a schedule change reaches everyone instantly
### 🦡 BadgerOne · In development
***One task a day keeps the badger away.*** We all have that one task we keep putting off. BadgerOne makes you pick it, then sends a persistent little badger to nag you until it's done.
- **Stack:** Expo, React Native, TypeScript
- Each morning, you pick the one task that matters most today
- One task only, with no endless to do list to hide behind
- The badger keeps nudging you through the day until it's checked off
### 🗓️ Roster · Live on the App Store
***Roster. Revise. Refine.*** Scheduling shouldn't eat your week. Roster brings shifts, departments and teams into one place, and lets AI handle the heavy lifting.
- **Stack:** React Native, TypeScript, AWS Amplify, Cognito, DynamoDB, Lambda
- Describe what you need, and AI scheduling builds multiple shifts from a single prompt
- Recurring shifts, a built in time clock and multi organization support
- Role based access, so admins, managers and employees each see what they need
